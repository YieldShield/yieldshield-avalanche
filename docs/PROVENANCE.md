# Provenance

The Avalanche pilot is newly authored in this repository, informed by YieldShield's existing Monad/Base/BNB split-risk product design. It is an independent implementation with Avalanche-specific epoch accounting and funded test assets, not a claim that the underlying split-risk idea is new. No private keys, deployment registries, environment files or historical contracts are copied. The MIT license retains YieldShield's copyright. React, React Router, Vite, viem and OpenZeppelin remain subject to their upstream licenses. Demo assets are explicitly unrelated to issuer-backed USDC.
